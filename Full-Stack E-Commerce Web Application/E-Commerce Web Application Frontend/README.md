# 🛒 E-COMMERCE FULL STACK APPLICATION

A complete Full Stack E-Commerce Web Application built using modern web technologies.  
This project provides a smooth shopping experience with product browsing, cart system, wishlist, authentication pages, and checkout flow.

---

## 🚀 Project Overview

This is a React-based E-Commerce frontend application with multiple pages and components for a complete shopping experience.

Users can:
- Browse products by categories
- Search products
- Add/remove items from cart
- Manage wishlist
- Register & Login
- Checkout orders
- View order success page
